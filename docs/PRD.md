# Product requirements — api

## Goal

Accept learner evidence and make authorized submissions available to teachers.

## Planned user journey

A learner synchronizes a saved attempt. A teacher reviews only an explicitly submitted attempt for their own class.

## Acceptance demonstration

Repeat a request after losing its response. Expect one confirmed attempt. Submit one of two attempts and verify only that submission appears for the assigned teacher.

Use synthetic accounts and record the build under test. Track delivery against the matching Linear stories.
